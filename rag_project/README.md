# Multi-Document RAG Research Assistant

A complete, fully functional, college-level computational RAG (Retrieval-Augmented Generation) application built completely onto modern Python endpoints.

## Documentation Index
All detailed documentation including setup, diagrams, academic papers logic, tests logic, presentations are found inside `project_report.md`.

## Standard Initialization Routine 
1. Build venv logic bounds: `python -m venv venv` 
2. Hook venv activation path.
3. Pipe install bindings: `pip install -r requirements.txt`
4. Replicate Configuration Token `.env` configuration file logic mapped to `GOOGLE_API_KEY`.
5. Trigger Streamlit IO: `streamlit run app.py`
